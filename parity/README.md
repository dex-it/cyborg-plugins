# parity/

Записанные сессии для проверки паритета с ai-cyborg (задача V-03 эпика переноса, [#38](https://github.com/dex-it/cyborg-plugins/issues/38)). Каталога сценариев пока нет: он наполняется на этапе 5, когда есть что проигрывать. Здесь зафиксирован формат, чтобы подставные программы из `fixtures/` и записи сходились уже сейчас.

## Запись

Один сценарий - каталог `parity/<сценарий>/` (идентификаторы S1..S22 из [карты переноса](https://dex-it.github.io/cyborg-plugins/development/roadmap/)):

| Файл | Что |
|---|---|
| `events.jsonl` | События хуков, которые получает приложение: то, что подставной `claude` пишет в `CYBORG_EVENTS` (`toolbox().eventList()`) |
| `output.txt` | Вывод pty как есть |
| `cli.json` | Ответы подставных `gh`, `glab`, `jira`, `claude plugin`, `ssh` на запросы: журналы вызовов набора (`toolbox().log(...)`) и их ответы |
| `expect.json` | Эталон: нормализованные события контрактов (`session.*`), строки дерева, панелей, меню, состояние видов |
| `manifest.json` | Версия записи, версия Claude Code, на которой снята, описание сценария |

Нормализация идёт на уровне событий контрактов и строк видов, а не DOM окна: после переноса вида в `<iframe>` обращение к `#tree` из `document` окна не работает.

## Повтор

Проигрыватель запускает сценарий на бандле `ai-cyborg` с подставными программами из `fixtures/` и сравнивает нормализованный результат с `expect.json`. Расхождение допустимо только записью в `allowlist.json`: сценарий, поле, причина, ссылка на решение. Запись, которой не пользуется ни одно расхождение, роняет проверку.
