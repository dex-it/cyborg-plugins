Бандл - именованный набор плагинов, который ставится пачкой. Плагин сам по себе мало что даёт: терминал сессии нужен вместе с агентом, дерево файлов - вместе с проектами. Бандл фиксирует такой набор один раз, а не заставляет каждое приложение собирать список вручную.

```json
{
  "format": 1,
  "id": "code-workspace",
  "version": "1.0.0",
  "title": "Работа с кодом",
  "description": "Проекты, дерево файлов, просмотр, git и поиск рядом с сессией.",
  "plugins": ["projects", "files", "viewer", "git", "search"]
}
```

Файл лежит в `bundles/<id>.json`. Это только список: ни кода, ни копий плагинов в бандле нет. Из списка сборка делает [поставку для приложения](/bundles/build/).

## Что даёт бандл

- **Готовый состав.** Приложение берёт `ai-cyborg` и получает всё, что нужно для рабочего места, не перечисляя тринадцать плагинов.
- **Проверку полноты.** Если плагин требует контракт (`requires`), а поставщика среди плагинов бандла нет, бандл не соберётся. Ошибку видит автор, а не пользователь при первом запуске.
- **Версию набора.** Бандл выпускается со своей версией, по ней приложение узнаёт, что набор изменился.

## Бандлы расширяют друг друга

Поле `extends` подключает другой бандл целиком. Так прикладные наборы строятся на базовых:

```json
{
  "format": 1,
  "id": "task-trackers",
  "version": "1.0.0",
  "title": "Задачи и MR",
  "description": "Задачи и MR из GitHub, GitLab и Jira.",
  "extends": ["code-workspace"],
  "plugins": ["trackers"]
}
```

Порядок: плагины расширяемых бандлов идут первыми, затем собственные, без повторов. Циклы в `extends` и ссылки на несуществующие бандлы - ошибка.

:::note[Надстройка требует основу]
Бандл проверяется сам по себе: плагины, чьи контракты нужны надстройке, должны быть в нём. Если `trackers` требует `cyborg.projects`, бандл либо включает плагин с проектами, либо расширяет бандл, где он есть. «Предполагается, что основа уже стоит» не работает: так сборка проверяется без чужих данных.
:::

## Запланированные бандлы

Первый набор повторяет приложение ai-cyborg ([карта переноса](/development/roadmap/)):

| Бандл | Что собирает |
|---|---|
| `agent-sessions` | Минимальное рабочее место: сессии Claude Code с уведомлениями и изоляцией |
| `code-workspace` | Проекты, дерево файлов, просмотр, git и поиск |
| `task-trackers` | Задачи и MR из GitHub, GitLab и Jira |
| `ai-cyborg` | Всё вместе: приложение ai-cyborg на ядре и плагинах |

Состав каждого - в [списке бандлов](/catalog/bundles/). Он строится из файлов репозитория, поэтому всегда совпадает с тем, что собирается.

## Свой бандл

Бандл добавляется pull request'ом так же, как плагин: файл `bundles/<id>.json` и проверка `npm run check`. Формат - на странице [«Формат бандла»](/bundles/format/).
