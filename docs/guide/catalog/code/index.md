Работа с репозиториями рядом с сессией: проекты, дерево файлов, просмотр, git, поиск.

:::note[Пока пусто]
Плагины этой категории ещё не перенесены в репозиторий. Что запланировано - в таблице ниже; свой плагин можно добавить уже сейчас ([как](/authors/new-plugin/)).
:::

## Запланированы

| Плагин | Что будет делать | Откуда |
|---|---|---|
| `projects` | Проекты: набор локальных репозиториев под одним именем | ai-cyborg |
| `files` | Дерево файлов сессии с отметками git | ai-cyborg |
| `viewer` | Просмотр файлов с подсветкой, сравнение с HEAD, правка Markdown, запуск файла в системном терминале | ai-cyborg |
| `git` | Ветка, статус, смена ветки, содержимое HEAD | ai-cyborg |
| `search` | Поиск файла по имени и строки в содержимом и среди изменений | ai-cyborg |
