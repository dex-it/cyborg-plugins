Сессии агента и всё, что с ними связано: вкладки, терминал, изоляция, уведомления, подсказки следующих шагов.

:::note[Пока пусто]
Плагины этой категории ещё не перенесены в репозиторий. Что запланировано - в таблице ниже; свой плагин можно добавить уже сейчас ([как](/authors/new-plugin/)).
:::

## Запланированы

| Плагин | Что будет делать | Откуда |
|---|---|---|
| `sessions` | Вкладки сессий в терминале ядра, делегирование дочерним сессиям, MCP-сервер сессий | ai-cyborg |
| `remote-sessions` | Удалённые сессии Claude Code по SSH: хосты проекта, агент на хосте, клоны, обрыв и подхват, MCP-туннель, голосовой ввод | ai-cyborg |
| `session-isolation` | Параллельные сессии в одном репозитории уходят каждая в свой worktree | ai-cyborg |
| `session-notifications` | Уведомление, когда сессия ждёт человека | ai-cyborg |
| `next-actions` | Кнопки следующих шагов, которые предлагает модель | ai-cyborg |
