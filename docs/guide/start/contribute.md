Плагин сюда может добавить кто угодно: правила одни для всех, а решение о слиянии принимают после обычного ревью.

## Путь

1. **Выберите категорию.** Список - в [каталоге](/catalog/). Подходящей нет - предложите новую в том же pull request: она заводится записью в `plugins/categories.json`.
2. **Заведите плагин из шаблона:**

   ```bash
   npm run new -- code my-plugin "Мой плагин"
   ```

   Появится `plugins/code/my-plugin/` с манифестом, главной частью, контрактом, видом, тестом и карточкой `README.md`.
3. **Допишите.** Манифест, код и тесты - как для любого плагина ядра ([руководство автору](https://dex-it.github.io/cyborg-harness/authors/)). Идентификатор выберите [по правилам пространств имён](/authors/namespaces/).
4. **Заполните карточку** в шапке `README.md`: название, фраза, статус ([формат](/authors/card/)).
5. **Прогоните проверки:**

   ```bash
   npm run check && npm run check:plugins && npm run typecheck && npm test
   ```

6. **Откройте pull request** в `master`. CI повторит то же на двух системах.

Подробности каждого шага - в разделе [«Автору плагина»](/authors/).

## Чего не нужно

- Править `manifest.json` под каталог: категории в нём нет, она определяется путём.
- Копировать плагин в несколько категорий: идентификатор один на весь репозиторий.
- Править или коммитить страницы `docs/guide/catalog/`: их строит сборка сайта.
