Плагин для этого репозитория - обычный плагин ядра плюс три вещи, которые нужны каталогу: место в дереве, карточка в README и идентификатор, не пересекающийся с чужими. Всё остальное - манифест, главная часть, виды, права, тесты - как в [руководстве автору плагина](https://github.com/dex-it/cyborg-harness/tree/master/docs/guide/authors) ядра.

| Страница | О чём |
|---|---|
| [Раскладка](/authors/layout/) | Где что лежит: `plugins/<категория>/<id>/`, что в каталоге плагина, зачем `categories.json` |
| [Новый плагин](/authors/new-plugin/) | `npm run new`, что создаётся, как довести до pull request |
| [Карточка плагина](/authors/card/) | Шапка `README.md`: поля, статусы, что попадёт на сайт |

## Что считается хорошим плагином

- **Делает одно.** Плагин с понятной границей: терминал сессии, дерево файлов, трекер. Всё, что нужно другим плагинам, отдаётся контрактом, а не импортом.
- **Просит минимум прав** и объясняет в README, зачем каждое. Права сайт перечисляет сам, смысл пишет автор.
- **Покрыт тестами на тест-ките** (`@cyborg-harness/testing`): ядро поднимается на самом плагине, а не на его подделке.
- **Не знает чужих плагинов по имени.** Только контракты: проверка импортов запрещает ссылаться на другой плагин.
- **Объявляет внешние программы.** Нужен `git`, `gh`, `jira`? Это поле `needs` в карточке: человек видит заранее, что поставить.
